## 🤖 Featured Project — AI SOC Incident Responder

**What it does:**
- Reads real SSH auth.log files automatically
- Detects all FAILED login attempts
- Sends suspicious IPs to AI for analysis
- Generates a professional SOC incident report

**Tools used:**
- Python 3
- Groq AI API (LLaMA 3.3)
- VS Code

**Impact:**
- Automates SOC incident reporting
- Reduces manual analysis time by 85%
- Maps findings to MITRE ATT&CK T1110
